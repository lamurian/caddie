# .agents/

Files that coding agents discover by convention when started in this repo.

| Path | Purpose |
|------|---------|
| [`skills/`](skills/README.md) | The Caddie Agent Skill (`skills/caddie/SKILL.md`) |

It is hidden so it stays out of the user's way, but it is ordinary tracked
content ([ADR 0025](../docs/adr/0025-skill-in-agents-dir.md)).

## Contributing

- Add something here only if agents look for it at this path.
- Agentic docs stay under 100 lines
  ([ADR 0012](../docs/adr/0012-agentic-docs-and-line-limits.md)).
- No secrets and no personal data.
